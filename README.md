# AnythingMCP for Cursor

AnythingMCP connects the business systems you already use to Cursor through one hosted MCP server. It ships 460+ ready connectors for ERP, accounting, e-commerce, CRM, messaging and databases, among them Etsy, Odoo, SAP, Shopify, WooCommerce, Amazon Seller, eBay, Telegram, WhatsApp Business, weclapp, Lexware Office, sevDesk, HubSpot, Salesforce, Printify, Pinterest, Google Sheets, PostgreSQL and MySQL, and it can turn any REST, SOAP, GraphQL or OData API into MCP tools.

## What you can do

- Ask about live business data from the editor: open invoices, today's orders, stock levels, customer history.
- Let the agent create drafts in your systems, such as a quote, an invoice or a product listing, with write tools that ask for confirmation.
- Query your own database with read-only SQL tools.

## Setup

1. Install the plugin from the Cursor Marketplace.
2. Cursor opens the AnythingMCP sign-in the first time a tool is used. Create a workspace or sign in; new workspaces get a 7-day trial.
3. In AnythingMCP, add the connectors you need from the catalog (some, such as Deutsche Bahn or OpenPLZ, need no API key at all).
4. Ask the agent, for example: "List my open Odoo invoices older than 30 days."

The plugin only points Cursor at `https://cloud.anythingmcp.com/mcp`. Credentials for your apps are stored encrypted in your AnythingMCP workspace and are never part of this repository.
